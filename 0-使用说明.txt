RE Lab 使用说明
========================================

只需要记住三个文件：

  1-一键部署.cmd   第一次使用，双击它。
  2-一键启动.cmd   平时使用，双击它，输入编号选择工具。
  3-一键卸载.cmd   不想用了，双击它，输入 YES 确认。

----------------------------------------
第一次使用
----------------------------------------

1. 双击“1-一键部署.cmd”。
2. 等待下载和解压完成，不要关闭窗口。
   首次约下载 1.2 GB，安装后总共约 4 GB。
3. 完成后双击“2-一键启动.cmd”。
4. 输入工具前面的编号，回车即可启动。
   例如输入 2 启动 Cutter，输入 5 启动 jadx。
5. 输入 H 可以打开“新手速查表”，里面写了每个工具最短的用法。
   新手建议先用 Cutter（第 2 项），它是简体中文界面。

----------------------------------------
卸载
----------------------------------------

1. 先关闭已经打开的工具。
2. 双击“3-一键卸载.cmd”。
3. 输入 YES 并回车。
4. 会删除 tools、downloads 和生成的配置，释放约 4 GB。
   这几个启动脚本会保留，方便以后再次一键部署。

----------------------------------------
常见问题
----------------------------------------

问：双击后窗口一闪而过？
答：右键文件，选择“以管理员身份运行”；或打开 PowerShell，进入本目录后执行：
    powershell -NoProfile -ExecutionPolicy Bypass -File .\Deploy-RELab.ps1

问：下载很慢？
答：脚本默认使用 GitHub 加速代理。如果代理不可用，可以运行：
    .\Deploy-RELab.ps1 -NoProxy

问：Ghidra 打不开？
答：Ghidra 12.2 需要 JDK 25，部署脚本已经把 JDK 25 放在 tools\jdk25。
    请通过“2-一键启动.cmd”启动，它会自动设置 JAVA_HOME。

问：怎么卸载 Python？
答：“3-一键卸载.cmd”会先调用 Python 官方卸载程序，再删除 tools 目录。
